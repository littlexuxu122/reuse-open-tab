# 重复打开时询问

Chrome 扩展。同一个地址已经开着时，新标签上会先询问。

- 选「回到原页面并刷新」：关掉新标签，把原来的窗口和标签拉到前面，再刷新。
- 选「保留这个新标签」，或按 Esc：两个标签都留着。

`#` 后面的锚点不同，仍算同一个页面。地址里的查询参数不同，则不算。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选这个仓库的文件夹。
4. 要检测本机 HTML（`file://`）时，在扩展详情里打开「允许访问文件网址」。

工具栏图标里可以暂停询问。短时间一下子打开很多标签（例如刚启动时恢复旧标签）不会弹确认框。
